# readlite
一个帮你专心阅读的、极简的chrome核心浏览器的阅读模式插件（edge、百分、360等也可以用）。可以调整网页底色、字体、字体大小、字距、行距、段距。可以全屏无扰显示。还可以将阅读模式下的网页布局导出为word文档。
A minimalist reading mode extension for Chromium-based browsers that helps you focus on reading. It allows you to adjust the page background color, font, font size, letter spacing, line spacing, and paragraph spacing. It supports distraction-free full-screen display. You can also export the webpage layout in reading mode as a Word document.
